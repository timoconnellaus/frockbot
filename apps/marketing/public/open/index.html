Your own deployment

Run it
yourself.

The installer sets up FrockBot in your Cloudflare account. Start from a published release and follow the install guide for the current prerequisites, authentication and service configuration.

You need the required Cloudflare services and a hostname in your account. The current Computer provider uses Fly Sprites. Infrastructure and model usage are billed by those services; the open-source licence does not include hosting.
