The shape

Always
on.

A Bot is a persistent Durable Object with a conversation, memory, routines, tools, and a desktop on a shared cloud computer. It keeps working after you close the laptop and comes back only when it needs an approval.

01

Persistent by default

Every Bot is its own Durable Object. History, notes and instructions survive across sessions, deploys and devices.

02

A real computer

Browser, filesystem and terminal on a Fly Sprite. Each Bot gets its own desktop and folders. Watch the screen or take control.

03

Routines and triggers

Cron schedules, webhooks and connected-app events wake a Bot and run a Turn without you in the loop.

04

Approvals in the loop

Spending, sending, publishing a plugin: each is an approval card on the Turn's own log. Allow once, or always.

Plugins

Everything a Bot does
is a plugin.

Plugins wrap the agent loop. They declare hooks on the loop's events, register tools under their own namespace, keep their own storage, and name the hosts they may reach. Each User's plugins mount into one Dynamic Worker with a hard CPU budget and a loopback into the kernel; a plugin that throws or overruns is quarantined and the Turn carries on.

Bots can write plugins too. Publishing one never runs it: the Bot puts an approval card in front of you naming the tools, hooks, grants and hosts it wants, and nothing mounts until you say so.

ADR 0026: Plugins → Architecture → 

// plugin.ts: one tool, one hook, its own storage
import type { PluginExecute, PluginHooks, PluginTool }
  from "@frockbot/applet-sdk/plugin";

export const tools: PluginTool[] = [{
  name: "note_add",
  description: "Keep one short note for this Bot.",
  inputSchema: { type: "object",
    properties: { text: { type: "string" } },
    required: ["text"] },
}];

export const execute: PluginExecute = async (tool, input, ctx) => {
  const stored = await ctx.storage?.get({ key: "notes" });
  const notes = stored?.status === "available" ? stored.value : [];
  await ctx.storage?.put({ key: "notes", value: [...notes, input.text] });
  return `Kept it. ${notes.length + 1} note(s) now.`;
};

export const hooks: PluginHooks = {
  "agent/tool-exposure": (payload) =>
    payload.tools.filter((t) => t.name !== "image_generate"),
};
  1. 1system-prompt/assemble add to or rewrite the prompt before the model sees it
  2. 2agent/tool-exposure hide, rename or add tools for this Turn
  3. 3agent/request change the model, the messages or the options on each request
  4. 4tools/pre-execute inspect or veto a tool call before it runs
  5. 5tools/post-execute reshape a result before it reaches the model
  6. 6agent/turn-stopping keep the Turn going, or let it end

Run it yourself

One command.
Your account.

bun run setup installs the same code frockbot.com runs into a Cloudflare account you own: Workers, Durable Objects, R2, Vectorize and Containers, with Cloudflare Access as the sign-in and no billing at all. You need a Workers Paid plan, one domain on the account, a free Zero Trust team, and a Fly token for the computer. Model, voice and connected-app keys are optional and each one only unlocks its own thing.

The web client and the container images are published with every release, so there is no Docker and no Flutter on your machine. A Mac app is built; the phone apps are on the way.

Read the install guide → Releases →
