# What import never creates

No Connection. No credential. No model binding. No webhook signing key. No
Memory. No Computer state.

An enabled Package is available account-wide after install; Connections stay
the importing User's explicit choice. Every server the template named
becomes a line on the review card telling them what they would have to
connect themselves.

If they apply and then ask you why a tool is still missing, that is usually
a Connection or a Plugin switch, not a failed import. Point at Connectors or
Plugins. Do not invent a second Bot to hold the missing reach.
