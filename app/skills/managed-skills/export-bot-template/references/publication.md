# Staging is not publishing

`bot_export_template` always stages `visibility: "private"`. The share exists
for this User and is shared with nobody.

Choosing `link` or `public` is a click in Bot settings. There is no tool
that sets visibility, and there is no tool that revokes a share. If they
want it public, send them to this Bot's settings and stop.

The card the tool draws is how you tell them what was packed. Do not
re-summarise the whole Bot from the catalog line of each Skill: the pack
already carried the bodies.
